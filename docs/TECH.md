## 4. Systems
### S01 Networking (NGO)
- Listen-server host, ≤4 clients. NetworkManager in Bootstrap; prefab list = NetworkPrefabsList asset generated by PrefabBuilder.
- Dev: UnityTransport 127.0.0.1:24565. Release: FacepunchTransport; LobbyService creates Steam lobby, stores host SteamId, friends join via overlay/invite.
- Authority:
  - Player: owner-authoritative `NetworkTransform` (AuthorityMode = Owner), tick 30. Server checks speed (>1.5x max → `TeleportRpc` back).
  - Vehicles/critters/props: server-authoritative NetworkTransform + `NetworkRigidbody` (non-authority rigidbodies kinematic, interpolate on).
  - Tools: NetworkObject; equip = server sets `NetworkObject.TrySetParent(player)` + NetworkVariable<ulong> holder. Use: owner sends `UseRpc(Vector3 origin, Vector3 dir, bool pressed)` ~30Hz while held; server runs hit logic. Local spray VFX plays immediately (prediction); others via NetworkVariable<bool> IsSpraying.
  - Economy/day: NetworkVariables.
- Late join: `SnapshotMessenger` sends dirt masks via CustomMessagingManager named message, `NetworkDelivery.ReliableFragmentedSequenced`.
- No host migration; host leaves → clients get summary + back to menu.
- Testing: MPPM virtual players (up to 4) in Editor; CLI builds with `-host`/`-join`.

### S02 Player (`PlayerMotor` w/ CharacterController)
- Tunables in BalanceData: walk 4.5, sprint 7, jump 4.8, accel 40, airAccel 8, friction 10 / foam 1.2, gravity 18.
- Foam floor: trigger volumes on layer FoamArea (spawned by foam decals) → motor reads `inFoam` count.
- Knockback: `AddKnockback(Vector3)` external velocity, decays 6/s; |v|>9 → Knocked 1.5s.
- Status flags: Knocked, Stung(slow), Soaked(slow 10% 3s), Carrying.
- Interact: `Physics.RaycastNonAlloc` 2.5m, layer Interactable; target implements `IInteractable { string Prompt; bool CanInteract(PlayerNet p); void Interact(PlayerNet p); }` → executed via ServerRpc.
- Grab: server-side; held Rigidbody velocity = (holdPoint - pos)*15, max mass 40, throw impulse = charge*14. Client sends Grab/Release/Throw RPC.
- Inventory: 4 slots (NetworkList<NetworkObjectReference>).
- Camera: Camera on owner only; others see third-person body; first-person arms only on owner (layer FPArms, rendered by overlay camera or URP Render Objects to avoid clipping).

### S03 Tools (`ToolBase : NetworkBehaviour`)
- ToolData: id, weight, range, coneDeg, rays, cleanRate(Vector3 RGB), knockback, wetnessDps, flags (Foam|Capture|Extinguish).
- SprayTool server tick 30Hz: `rays` raycasts (washer 5) within cone (`RaycastNonAlloc`, mask water_hit); per hit:
  - has `DirtPainter` (via collider attachedRigidbody/GetComponentInParent cached map) → `AddStroke(localPos, radius=lerp(0.15,0.4,dist/range), strength=cleanRate*dt, type)`
  - Rigidbody → `AddForceAtPosition(dir*knockback, point, ForceMode.Force)`
  - PlayerStatus → `AddKnockback(dir*knockback*0.4f*dt*30)` via ClientRpc to owner (owner-authoritative motor)
  - CritterBase → `AddWetness(wetnessDps*dt)`
  - static floor → foam/puddle decal (URP DecalProjector, pooled max 64)
- HoseTether: anchor = bay reel; dist > hoseLen → pull player back (knockback toward anchor); visual LineRenderer w/ 8-point verlet (local only).
- Towel: SphereCast 1.0m, B channel only, requires mouse delta > threshold (wiping motion).
- ShopVac: OverlapSphereNonAlloc in 2m cone; pulls Rigidbodies tagged VacSmall; destroys Trash on contact.
- NetPole: stunned critter in capture area → attach to `Socket_Capture`; release inside Cage trigger → `GameEvents.CritterCaptured`.

### S04 Dirt painting (core tech — highest risk, build first in M1)
Goal: per-vehicle mask that tools erase in world space; cleanliness % readback.

Mesh requirement: unique non-overlapping **UV2** (`uv2`, i.e. TEXCOORD1). Prototype: model import "Generate Lightmap UVs" = on. Paint uses world distance → no seams across UV islands.

Per-vehicle textures (size from VehicleData: S 256, M 512, L/XL 1024):
- `_DirtInit` RenderTexture ARGB32 (generated once at spawn by Blit with noise shader seeded per vehicle): R mud, G grease, B 0, A coverage(1 on UV2 islands — rendered via unwrap pass with white).
- `_CleanAcc` RenderTexture ARGB32, never cleared: R mudCleaned, G greaseCleaned, B spotsAdded, A spotsRemoved.
- `_FoamMask` RenderTexture R8 256: foam strokes write 1; each frame (only if foam active) full-quad pass subtracts dt/20.

Paint pass (`DirtPainter`, CommandBuffer executed via `Graphics.ExecuteCommandBuffer` in LateUpdate when strokes pending):
```
cmd.SetRenderTarget(_CleanAcc);
paintMat.SetVectorArray("_Brushes", brushes);   // xyz object-space pos, w radius (max 32)
paintMat.SetVectorArray("_BrushStr", strengths); // rgba per channel (R,G,B add, A towel)
paintMat.SetInt("_BrushCount", n);
foreach submesh: cmd.DrawMesh(bodyMesh, Matrix4x4.identity, paintMat, sub, pass:0);
```
`DirtUnwrapPaint.shader` (HLSL, URP-compatible unlit, `Blend One One`, `Cull Off`, `ZTest Always`, `ZWrite Off`):
```
struct a2v { float4 vertex:POSITION; float2 uv2:TEXCOORD1; };
struct v2f { float4 pos:SV_POSITION; float3 objPos:TEXCOORD0; float2 uv2:TEXCOORD1; };
v2f vert(a2v v){ v2f o; float2 p = v.uv2*2-1;
  #if UNITY_UV_STARTS_AT_TOP
    p.y = -p.y;
  #endif
  o.pos = float4(p,0,1); o.objPos = v.vertex.xyz; o.uv2 = v.uv2; return o; }
float4 _Brushes[32]; float4 _BrushStr[32]; int _BrushCount; sampler2D _FoamMask; float _GreaseNeedsFoam;
float4 frag(v2f i):SV_Target{
  float4 acc=0; float foam = tex2D(_FoamMask,i.uv2).r > 0.1;
  for(int k=0;k<_BrushCount;k++){
    float d = distance(i.objPos,_Brushes[k].xyz);
    float f = 1 - smoothstep(_Brushes[k].w*0.5,_Brushes[k].w,d);
    float4 s = _BrushStr[k]; s.g *= lerp(1, foam, _GreaseNeedsFoam);
    acc += s*f; }
  return acc; }
```
- Spots generation: washer strokes also add B = 0.4*(R+G strength) where it cleaned; towel stroke writes A (spots removed).
- Re-dirt (slime, pigeons, turret): second pass using same shader with `BlendOp RevSub` on R/G channels (pass 1). `// VERIFY` y-flip on D3D/Vulkan in DirtTest scene.
- Foam stroke: same unwrap shader writing to _FoamMask (pass 2, `Blend One One`).

`VehicleDirt.shader` (URP Lit-style simple or HLSL; on Body material, samples UV2):
```
float4 init = SAMPLE(_DirtInit, uv2); float4 cl = SAMPLE(_CleanAcc, uv2);
float mud = saturate(init.r - cl.r); float grease = saturate(init.g - cl.g); float spots = saturate(cl.b - cl.a);
albedo = lerp(base, _MudCol, mud*0.9); albedo = lerp(albedo, _GreaseCol, grease*0.8);
smoothness = lerp(0.75, 0.1, max(mud,grease)); spots → speckle mask via noise threshold darkening.
```
Material per vehicle instance via MaterialPropertyBlock (set RT textures) — no material instancing leaks.

Readback (`DirtReadback`, server only, every 0.5s): Blit `DirtEval.shader` (computes per-texel weighted dirt `(0.5*mud+0.3*grease+0.2*spots)*coverage` and coverage) into 64x64 RGFloat RT → `AsyncGPUReadback.Request` → C# sum → `cleanPct = 1 - sum(dirt)/sum(coverage)`. Never read full-res; never sync GetPixels.

Net (`DirtNetSync`): server batches strokes at 10Hz → `ApplyStrokesClientRpc(NetworkObjectReference v, DirtStroke[] s)` (DirtStroke: INetworkSerializable {half3 pos, half radius, half4 str, byte type}). Clients paint visually only. cleanPct is server NetworkVariable<float>. Late join: server AsyncGPUReadback full _CleanAcc → EncodeToPNG → SnapshotMessenger → client LoadImage → Blit into RT.

Fallback backend (if UV2 painting fails on a mesh): per-vertex colors with CPU sphere-distance; both implement `IDirtBackend { AddStroke; float CleanPct; byte[] Serialize(); Deserialize(byte[]); }`.

Interior trash: Rigidbody props spawned at `Socket_Interior`, tagged Trash; Vehicle counts remaining.

### S05 Spray VFX
VFX Graph (GPU) for stream/mist where supported; fallback ParticleSystem for Steam Deck low preset. Splash pooled at ray hits (max 1 per ray per 0.1s). Foam: DecalProjector + particle blobs. Audio loop with pitch by pressure level; impact layer when hitting vehicle.

### S06 Customer/Vehicle flow (`DayManager` server, `DayLogic` pure)
- Spawner picks VehicleData by week tier weights + rep. Vehicle = kinematic Rigidbody moved by `VehiclePathMover` along waypoint list (spline via com.unity.splines optional; simple waypoints OK) 6 m/s: road → queue slot → bay stop → exit.
- States: Arriving, Queued, Parking, Washing, Inspecting(2s), Leaving, Angry.
- Finish: bay DONE button (IInteractable) or cleanPct ≥ 1. → `EconomyCalc.CalcPay` → pay; <60% → refuse, angry leave.
- Patience bar: world-space UI above car.
- Doors/trunk: `VehicleDoor` rotates hinge transform (lerp), IInteractable, NetworkVariable<bool> open.
- Driver: invisible (tinted windows joke) in MVP.

### S07 Critters (`CritterBase : NetworkBehaviour`, NavMeshAgent server-only)
- NavMesh: NavMeshSurface (AI Navigation pkg) baked for SudsyLot; agent types Small(r0.3) / Large(r0.8).
- State machine (enum + switch in plain C# `CritterBrain` for testability): Hidden, Reveal(1s, sting), Idle, Wander, Chase, Flee, Steal, Act, Stunned, Captured, Escaped.
- wetness 0..100, decay 5/s; ≥100 → Stunned stunTime, then 0.
- Per-critter override `OnAct(float dt)` ≤150 lines.
- SurpriseTrigger: OnOpen(socket) / OnCleanPct(x) / OnTimer(range); server rolls at vehicle spawn.
- BeeSwarm = one NetworkObject (sphere collider) + local boids particle visual.
- MudSlime split: wetness ≥50 & gen<3 → despawn, spawn 2 at scale 0.6, hp 0.6.

### S08 Economy — `EconomyCalc` static pure: `CalcPay(PayContext) → PayResult`, `RepDelta`, `ArrivalInterval`, `Rent(week, day)`. Fully EditMode tested.
### S09 Upgrades — ShopUI lists UpgradeData; `BuyRpc` → EconomyState.TryBuy; effects via `Upgrades.GetMult(Stat)` read at use time.
### S10 Day/Week — DayManager timers + DailyEvent ScriptableObjects (`Apply()/Revert()`), DaySummary struct → DaySummaryUI.
### S11 Voice — Facepunch `SteamUser.VoiceRecord`/`ReadVoiceData` → send via unreliable custom message → `SteamUser.DecompressVoice` → AudioClip stream on player head AudioSource (3D, maxDistance 20). M6+.
### S12 UI — uGUI (or UI Toolkit; pick uGUI for world-space bars). Crosshair, slots, prompts, money/rep/timer, bay cards, ping markers, toasts. Full gamepad navigation (EventSystem + InputSystemUIInputModule).
### S13 Audio — AudioMixer groups Master/Music/SFX/Voice/UI; music state per GameState + sting overlay.
### S14 Save — JSON {version, weekUnlocked, upgrades{}, cosmetics[], stats{}} on day end.
### S15 Props — Rigidbodies layer Prop, masses in BalanceData, max 80 active, sleep thresholds default.
### S16 Respawn — no death; y < -20 → respawn at lockers.

## 6. Performance budgets
60fps Steam Deck low: ≤150k tris visible, ≤300 batches (SRP Batcher on), active painters ≤3 (only occupied bays being sprayed), particles ≤4k, GC alloc 0 B/frame in gameplay (check Profiler).
