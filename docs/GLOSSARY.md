# 용어집 (GLOSSARY) — 게임 안 한국어 표시 텍스트 기준

M4.9 G8 (2026-11-19). 대상: UI·튜토리얼·도움말·간판·팝업·README 등 **플레이어가 읽는 텍스트만**. 코드·변수·클래스·씬 오브젝트 이름(Bay, Host, Ping …)은 그대로 둔다.
원칙: 게임을 처음 하는 일반인이 바로 알아듣는 말. 영어식·개발 용어는 쓰지 않는다. 키 이름(WASD, Shift, Space, Ctrl, Esc, F3 …)은 키보드에 적힌 그대로 둔다. 새 텍스트도 이 표를 따른다.

| 바꾸기 전 | 바꾼 뒤 | 비고 |
|---|---|---|
| 베이 (베이 1, 베이 버튼, 베이 카드) | 차고지 (차고지 1, 차고지 버튼, 차고지 정보창) | 세차 칸 |
| 로비 | 대기실 | 이미 '대기실'로 쓰던 것 유지 |
| 호스트 (버튼) | 방 만들기 | '호스트 (참가 코드 발급)' → '방 만들기 (참가 코드 발급)', 'IP로 호스트' → 'IP로 방 만들기' |
| 호스트 (사람) | 방장 | '호스트가 게임을 종료했습니다' → '방장이 …' |
| 서버 (가득 참 등) | 방 | '서버가 가득 찼습니다' → '방이 가득 찼습니다' |
| 호스트 / 서버 / 클라이언트 (F3 연결 정보) | 방장 / 참가자 | |
| FPS / RTT (F3) | 프레임 / 지연 | |
| Relay (오류 문구) | 참가 코드 (기능) | '참가 코드'는 그대로 유지 |
| 핑 | 위치 표시 | 마우스 휠 클릭 |
| 슬롯 (도구 슬롯) | (도구) 칸 | 1–4 |
| 노즐 넓게/좁게 | 물줄기 넓게/좁게 | 세척기 오른쪽 클릭 |
| 보스 (손님) | 특별 손님 | '보스 손님 등장!' → '특별 손님 등장!', 차 이름 접두어 |
| 볼륨 (전체 볼륨) | 음량 (전체 음량) | |
| 시야각 (FOV) | 시야 넓이 | 설정 |
| 수직 동기화 | 화면 찢김 방지 | 설정 |
| UI 크기 | 화면 표시 크기 | 설정 |
| Y축 반전 | 위아래 시점 반전 | 설정 |

그대로 두는 말 (이미 일반적): 튜토리얼, 도움말, 설정, 해상도, 전체 화면, 그래픽 품질, 마우스 감도, 참가 코드, IP·포트·포트 포워딩(고급 메뉴 안에서만), 키 이름.
