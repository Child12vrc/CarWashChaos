세차장 대소동 (CarWashChaos) v0.8 — 테스트 빌드
====================================================

최대 4명이 함께하는 1인칭 협동 세차 게임입니다.

v0.8에서 바뀐 점
- 바닥·벽이 겹쳐서 깜빡이던 곳(도로·차선·차고지 바닥·펜스·캐노피 띠 등)을 모두 고쳤습니다. 자동 검사로 겹치는 면 0개를 확인합니다.
- 바닥 글자(입구·서행·출구·차고지 번호)와 간판·안내판 글자가 선명해졌습니다. 실제 도로처럼 세로로 길게 그려지고, 멀리서 비스듬히 봐도 깨지지 않습니다.
- 글자가 벽·물체를 뚫고 보이던 문제를 고쳤습니다. 이름표도 벽 뒤에서는 가려지고 30m보다 멀면 숨겨집니다.
- 손님 타이머: 벽 뒤에 있는 차는 작고 흐리게, 10초 경고는 그대로 진하게 표시됩니다. 상단 상태 바와 겹치지 않습니다.
- 들고 있는 손이 벽 속으로 파묻히지 않습니다(손은 따로 그림). 자판기가 사무실 일정판을 가리던 문제를 고쳤습니다.

v0.7에서 바뀐 점
- 세차장이 한국식 셀프 세차장으로 바뀌었습니다: 큰 지붕(캐노피) 아래 차고지 3칸, 칸마다 결제기·천장 붐 암·폼브러시 거치대·
  호스 릴·배수구, 출구 쪽 건조·진공 구역, 입구 가격표·안내판, 노면 '입구/서행/출구', 자판기·벤치·파라솔 등 소품. 출구 램프가 동쪽 끝으로 옮겨졌습니다.
- 낮 → 밤: 영업하는 동안 해가 지고(08:00 → 20:30), 밤에는 별·달이 뜨고 가로등·간판·차 헤드라이트가 켜집니다. 구름이 흘러갑니다.
- 차고지 천장 조명 + 벽 스위치([E]로 켜고 끄기, 모두에게 같이 보임). 밤이 되면 자동으로 켜집니다.
- 닉네임: 처음 실행하면 메인 메뉴 위쪽 칸에 닉네임(2~12자, 한글 가능)을 정해 주세요. 이름표·대기실·결산·입장/퇴장 알림에 나옵니다.
- 옷장: 사물함 앞에서 [E] 또는 Esc → '옷장'. 내 캐릭터를 보면서 외형 12종과 내 색을 고릅니다(다음에도 기억). 대기실의 Z/X/C 키는 없어졌습니다.
- 손님 타이머: 줄 선 차와 세차 중인 차 위에 원형 타이머(초)가 뜹니다. 10초 남으면 깜빡이고 화난 얼굴이 나오며,
  0초가 되면 줄 선 손님은 '떠남! -평판'. 줄이 한 칸 줄 때마다 기다리는 손님이 10초 더 참아 줍니다. 화면 밖이면 가장자리에 화살표.
- 화면 위 상태 바 하나로 정리: 보유 돈 · 오늘 번 돈 · 임대료(얼마 더 필요한지) · 평판(별+숫자) · 시각/남은 시간.
  돈이 바뀌면 +$/-$가 뜨고, 차고지 카드에 청결 목표 80%(95%는 보너스) 표시가 생겼습니다.

v0.6에서 바뀐 점 (중간 테스트 빌드)
- 거품: 폼건 거품이 차에 두껍게 쌓이고 몽글몽글 덩어리가 생기며, 시간이 지나면 아래로 흘러내립니다.
  물로 헹구면 거품이 씻겨 내려가 바닥에 거품 물이 고입니다.
- 물기 닦기 보너스: 다 씻은 차를 수건으로 닦아 물기까지 없애면 반짝이고, 정산 때 팁(+15%)을 더 받습니다.
- 운전석에 손님이 앉아 있습니다. 숨 쉬고 하품하고, 가까운 플레이어를 쳐다봅니다. 얼굴에 물을 뿌리면 화를 냅니다.
- 동물도 [F]로 잡아서 들고 다니거나 던질 수 있습니다. 도구로 치면 날아가서 데굴데굴 구르고 말랑하게 흔들립니다.
- 넘어진 동료의 몸이 더 흐느적거립니다. 휘두르기가 맞으면 화면이 살짝 멈칫하고 흔들리며 조준점이 빨갛게 표시됩니다.
- 넘어진 몸 처리를 가볍게 해서 네트워크 사용량을 줄였습니다(4명 + 동물 많을 때도 부드럽게).
- 용어 정리: '베이' → '차고지', '호스트' → '방장', '서버' → '방' 등 화면 문구를 쉬운 말로 바꿨습니다.

v0.5에서 바뀐 점
- 멀티플레이 버벅임 개선: 다른 플레이어·차·물건이 끊기거나 떨리며 움직이던 문제를 고쳤습니다.
  (참가 코드 방식에서도 부드럽게 보입니다. 참가 코드 서버가 잠깐 응답하지 않으면 자동으로 다시 시도합니다)
- 바닥이 같은 무늬로 반복되어 보이지 않게 했습니다. 기름 얼룩·타이어 자국·균열·차선 화살표·맨홀 등이 생겼습니다.
- 담장·벽 밑에 풀과 잡초, 팔레트·드럼통·쓰레기 같은 소품을 배치했습니다. (차가 다니는 길은 막지 않습니다)
- 아스팔트·콘크리트·벽돌·금속 벽·셔터·차 실내 바닥과 시트에 실제 재질 텍스처를 입혔습니다. 차의 진흙도 더 진흙 같아졌습니다.
- 진흙 슬라임이 새 3D 모델로 바뀌었습니다.

v0.4에서 바뀐 점
- 처음 시작하면 튜토리얼(5단계)이 왼쪽에 나옵니다. Backspace로 건너뛸 수 있고, Esc → 설정 → [도움말] 탭에서 다시 볼 수 있습니다.
- 화면 표시를 작고 차분하게 정리했습니다. Esc → 설정 → 화면의 "화면 표시 크기"로 조절할 수 있습니다.
- 도구를 양손으로 듭니다(1인칭에서도 손이 보입니다). Q로 도구를 휘두르면 동료는 넘어지고 동물은 기절합니다.
- 물이 닿은 바닥·벽은 젖고, 오래 뿌리면 물웅덩이가 생깁니다(시간이 지나면 마릅니다). 가벼운 물건은 물줄기에 밀립니다.
- 더러운 차는 거칠고 뿌연 먼지, 씻은 곳은 반짝이고 매끈하게 보입니다. 차 문을 열면 실내(좌석·핸들·대시보드)와 쓰레기가 보입니다.
- 버그 수정: 점프 중 대각선 이동 + 시점 회전 시 비정상 가속, 2번째 플레이어가 막힌 차고에 스폰되던 문제,
  간판 글자가 물체를 뚫고 보이던 문제, 상자 메시 깜빡임. 던지기 힘 2배.


1. 실행하기
-----------
1) 압축(zip)을 원하는 폴더에 "모두 압축 풀기" 합니다. (zip 안에서 바로 실행하지 마세요)
2) CarWashChaos 폴더 안의 CarWashChaos.exe 를 실행합니다.
3) "Windows의 PC 보호" 파란 창이 뜨면 [추가 정보] → [실행]을 누릅니다.
   (서명되지 않은 테스트 빌드라서 나오는 안내입니다)

필요 사양: Windows 10/11 64비트, DirectX 11 이상 그래픽카드, 인터넷 연결(코드 방식)


2. 친구와 같이 하기 — 참가 코드 방식 (기본, 추천)
------------------------------------------------
서로 다른 집·다른 인터넷이어도 됩니다. 공유기 설정이나 포트 열기가 필요 없습니다.

[방장]
1) 메인 메뉴에서 [방 만들기 (참가 코드 발급)]을 누릅니다.
2) 세차장에 들어가면 화면 오른쪽 위에 6자리 "참가 코드"가 크게 나옵니다. (예: K7Q2MD)
3) Esc를 누르면 마우스가 풀리고, 코드 옆 [복사] 버튼으로 코드를 복사할 수 있습니다.
4) 카카오톡 등으로 친구에게 코드를 보내 줍니다.

[참가하는 친구]
1) 메인 메뉴의 입력칸에 받은 코드 6자리를 입력합니다. (대소문자·띄어쓰기 상관없음)
2) [코드로 참가]를 누릅니다.

- 코드는 방장이 게임을 켤 때마다 새로 바뀝니다.
- 방장이 게임을 끄면 모두 메인 메뉴로 돌아갑니다.
- "코드에 해당하는 방을 찾지 못했습니다"가 나오면 코드를 다시 확인하거나, 방장이 다시 만든 방의 새 코드를 받으세요.


3. IP로 같이 하기 (고급 — 같은 공유기/LAN)
------------------------------------------
같은 집·같은 와이파이라면 메인 메뉴 [고급 (IP로 플레이)]에서도 할 수 있습니다.

[방장] [IP로 방 만들기]를 누릅니다. 고급 화면과 게임 안 오른쪽 위에 "내 사설 IP : 포트"가 나옵니다. (예: 192.168.0.12 : 24565)
[친구] 고급 화면 입력칸에 방장의 IP(예: 192.168.0.12)를 넣고 [IP로 참가]를 누릅니다.

※ Windows 방화벽 허용 (IP 방식의 방장만 필요)
  처음 [IP로 방 만들기]를 누르면 "Windows 보안 경고 — 방화벽에서 일부 기능을 차단했습니다" 창이 뜹니다.
  → "개인 네트워크"에 체크하고 [액세스 허용]을 누르세요.
  이미 "취소"를 눌렀다면: 시작 → "Windows Defender 방화벽" → "앱 또는 기능이 Windows Defender 방화벽을 통과하도록 허용"
  → [설정 변경] → CarWashChaos 를 찾아 "개인"에 체크 → [확인].
※ 다른 인터넷(다른 집)과 IP 방식으로 하려면 공유기 포트 포워딩(UDP 24565)이 필요합니다. 이 경우엔 2번의 참가 코드 방식을 쓰세요.
※ 참가 코드 방식은 방화벽 설정이 필요 없습니다.


4. 게임 진행
------------
1) 대기실: 모두 [R]로 준비합니다. (옷은 사물함 앞 [E] 또는 Esc → 옷장에서 외형 12종·색 고르기 — 내 색은 다른 사람에게 몸 외곽선과 머리 위 이름표로 보입니다)
2) 사무실 일정판을 보고 [E] → 영업 시작.
3) 손님 차가 차고지에 들어오면 고압 세척기 등으로 깨끗하게 씻습니다.
4) 다 씻었으면 차고지 안쪽 벽의 버튼을 보고 [E] "세차 완료! 정산하기" → 검사 → 돈을 받습니다.
5) 하루가 끝나면 정산 화면이 나옵니다. [Enter]로 다음 날.
   차 안의 쓰레기, 갑자기 튀어나오는 동물들도 처리해야 합니다!

6. 알려진 문제 (v0.8)
---------------------
- 테스트 빌드입니다. 1주차 영업일 위주이며 상점·업그레이드 등 진행 요소(M5 이후)는 아직 없습니다.
- 결제기·붐 암·건조/진공 구역·자판기 같은 셀프 세차장 소품은 아직 장식입니다(누르거나 쓸 수 없음). 모양도 임시(단순 도형)입니다.
- 해치백·세단·픽업·미니밴·몬스터 트럭, 소품, 도구, 동물(너구리·주머니쥐·진흙 슬라임·벌)은 3D 모델로 바뀌었습니다.
  나머지 차종(아이스크림 트럭 등 후반 차량·다른 특별 손님)은 아직 임시 모양(그레이박스)입니다. (1주차에는 거의 나오지 않습니다)
- 청소기(T04)는 아직 들고 쓰는 도구가 아니라 출구 쪽 건조·진공 구역의 장식입니다. 차 안 쓰레기는 손으로 주워 버립니다.
- 몬스터 트럭 지붕처럼 손이 닿지 않는 곳, 차 밑면, 눈에 거의 안 보이는 옅은 얼룩(5% 미만)은 청결도 계산에서 빠집니다.
- 음성 채팅(V)은 아직 동작하지 않습니다. 디스코드 등을 함께 써 주세요.
- 참가 코드 방식은 인터넷이 필요하며, Unity Relay 서버를 거치므로 IP 방식보다 지연이 조금 더 있을 수 있습니다.
- 인터넷이 불안정하면 다른 플레이어가 순간 이동하듯 보일 수 있습니다. 10초 이상 응답이 없으면 메인 메뉴로 돌아갑니다.
- 진행 상황은 아직 저장되지 않습니다. 게임을 다시 켜면 1주차 1일차부터 시작합니다.
- 처음 실행 시 전체 화면입니다. Esc → 설정 → 화면에서 창 모드·해상도를 바꿀 수 있습니다.

문제가 생기면 다음 로그 파일을 같이 보내 주세요:
  %USERPROFILE%\AppData\LocalLow\DefaultCompany\CarWashChaos\Player.log
